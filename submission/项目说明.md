# paper-agent 项目说明

> 2026 江苏省 AI+科学与工程创新实践黑客松 · 选题：**科研 Agent 与 Harness 工程**
> 作品：基于 Agnes Harness（AGH）的**可审计、可复现、可故障恢复**的科研流水线 Agent

---

## 1. 问题来源

AI Agent 开始进入科研流程（文献调研 → 数据清洗 → 实验 → 验证 → 报告），但当前科研
Agent 普遍存在三个信任缺口：

1. **不可复现**：LLM 驱动的流程没有确定性保证，同一问题两次运行结论可能漂移；
2. **不可审计**：结论与证据脱钩——报告里的数字无法追溯到原始数据与计算过程；
3. **异常即黑箱**：进程崩溃、检索失败、结果篡改发生时，Agent 要么静默降级，要么
   丢失全部进度，无法判断"哪一步还能信"。

我们选择**固态电解质电导率排序**（硫化物电解质筛选，真实 DOI 文献域）作为任务载体：
这是一个有明确科学输出、可确定性重跑、可注入故障的小闭环，恰好能完整暴露并解决
上述三个缺口。

## 2. 目标

- 交付一个在 **AGH 之上**运行的科研 Agent：7 个工具覆盖规划、执行、验证、报告、
  引文回查、断点续跑、状态查询全链路；
- 每一次运行产生**append-only 双账本**（事件流 + 证据流），结论逐条绑定证据锚点
  `EV-XXXX`（含文件 SHA-256），0 命中也留证；
- **确定性**：相同输入两次执行，实验产物逐字节一致（SHA-256 全等），验证器独立复跑
  比对；
- **故障恢复**：重试 → 降级 → 崩溃断点 → 断点续跑，四类故障注入用例全部真实触发并
  恢复，状态机终态守卫杜绝非法回退；
- 全部交付物零第三方依赖（Python 核心仅标准库），任何机器 `python + node` 即可复验。

## 3. 核心方法

### 3.1 分层架构（Harness 工程视角）

```
AGH（Agnes Harness，赛事指定运行底座）
 └─ paper-agent-tools 插件（JS 薄壳，7 个 sciret_* 工具，Cordis 对象范式注册）
     └─ core/paper_agent（Python 核心，零第三方依赖）
         ├─ state.py       有限状态机 + 终态守卫 + events.jsonl（append-only）
         ├─ provenance.py  证据账本 provenance.jsonl + 结论↔证据强绑定 + 引文渲染
         ├─ steps.py       P1–P5 流水线调度：重试 / 降级 / 崩溃注入点 / resume
         ├─ chaos.py       故障注入矩阵（p1_fail_first / p1_fail_all / kill_after_p2 / mutate_summary）
         ├─ verify.py      P4 独立复跑 + 5 项递归容差校验
         ├─ report.py      P5 报告生成：每条结论必须携带 [EV-XXXX]，无证据快速失败
         └─ cli.py         单 JSON stdout 契约（UTF-8 强制）
     └─ experiments/arrhenius_rank.py  确定性实验脚本（打分排序 + 图表）
```

**设计原则**：JS 薄壳只负责把工具调用转成 Python CLI 子进程，业务真理全部落在
Python 核心 + 落盘账本；AGH 的 LLM 编排层即使替换，流水线行为与证据链不变。

### 3.2 五步状态机

`P1 文献检索 → P2 数据清洗 → P3 实验执行 → P4 复现验证 → P5 证据报告`
每步 PENDING→RUNNING→DONE/SKIPPED/FAILED 严格转移；DONE 为终态（重复调用幂等复用）；
FAILED run 不可再 finish(DONE)。attempt 计数、重试、降级事件全部写入 events.jsonl。

### 3.3 证据先行（Evidence-first）

任何步骤产物落盘即登记 `EV-XXXX`（kind、相对路径、SHA-256、producer_step）；
P5 报告的结论 C1–C5 逐条引用已存在的 EV，缺证据直接抛 `EvidenceError` 拒绝生成。
`sciret_cite` 可对任意 EV 回查引文与哈希。

### 3.4 故障注入与恢复（验证严谨与异常处理）

| 用例 | 注入 | 期望行为 | 自动化验证 |
|---|---|---|---|
| A `p1_fail_first` | P1 第 1 次尝试抛瞬时错 | 重试 1 次成功，degraded=false | 单测 + demo_failure |
| B `p1_fail_all` | P1 三次尝试全失败 | 降级为全语料命中，degrade 事件留痕 | 单测 + demo_failure |
| C 崩溃续跑 | P2 后进程被杀 | resume 只补跑 P3–P5，DONE 步骤复用 | 单测 |
| D `mutate_summary` | 复跑子进程环境变量注入篡改 | P4 五项校验精确定位 top3 位置项 FAIL，run FAILED | 单测 + demo_failure |
| E2/E3 `kill_after_p2` | P2 落账后 `os._exit(137)` **真实杀死进程** | 账本逐行可解析，断点 P3 PENDING，`sciret_resume` 续跑至 DONE | 单测（子进程真实退出码断言） |

## 4. AGH 执行流程（真实跑通，非模拟）

1. **插件安装**：`package inspect "file:./plugins/paper-agent-tools"` → `package add`
   （AGH 安全设计要求**交互式 TTY 人类确认**，我们提供 `demo/reinstall_plugin.ps1`
   以真实控制台 + 键盘输入注入等价完成）→ `package trust <integrity> <capabilityHash>`
   → `package enable`；最终状态 `desired=enabled actual=running trusted=true`。
2. **会话执行**：daemon 携带 `paper-agent_PYTHON` / `paper-agent_ROOT` 环境变量；
   `agnes -p --cwd <项目根> "<科研目标 prompt>"` 打印模式会话，LLM 按计划调用
   `sciret_plan → sciret_run_step(P1..P5) → sciret_verify → sciret_report →
   sciret_cite → sciret_status`；第二轮演示
   `sciret_run_step(P2, chaos=kill_after_p2) → 子进程真亡(137) → sciret_status
   (断点) → sciret_resume → DONE`。
3. **证据导出**：`agnes export <SESSION_ID> --format agnes -o evidence/session-full.jsonl`，
   共 **21 条 tool/call + 21 条 tool/result**，7 个工具名全部出现（闸门要求 ≥6 条）。
4. **审计包**：`bash audit-pack-template/build_audit_pack.sh <RUN_ID>` 归集
   state / events / provenance / conclusions / verification / report / 会话导出为
   `audit-pack/`，评审可离线逐行核验。

## 5. 模型信息（赛事申报要求）

| 项 | 值 |
|---|---|
| 模型名称 / 版本 | **Agnes 3.0 Flash**（`agnes-3.0-flash`，route `account-acct-60077bdf-…`，baseUrl `https://api.agnes-ai.cn/v1`，经 `AGH doctor provider --probe` 验证可用） |
| 使用环节 | 仅用于 **AGH 会话内的任务编排**：把用户科研目标拆解为工具调用计划、按工具返回（含错误/降级/崩溃）决定下一步、生成中文结论总结 |
| 调用方式 | AGH CLI 打印模式 `agnes -p`（daemon 持有 credential `secret://agnes-ai/…`，密钥只存 `~/.agh` 与 `.env`，绝不入库）；LLM 不直接产出科学数据——所有数字均由本地确定性实验与验证器产生 |
| 运行底座 | Agnes Harness（源码构建 `packages/cli/dist/local/agnes.mjs`，Node 24.15），插件经 inspect/add/trust/enable 全链路加载 |

**边界声明（2026-10-02 修订后口径）**：
模型参与**检索式生成与相关性筛选**，但**不产生任何数值与结论**。全部数值来自
公开数据集（OBELiX，每条附原始论文 DOI）与本地确定性计算；模型的全部判断以
`judgment` 级对象**全额留痕**（含被排除项与理由），不进入结论，可被复核与反驳；
代码级强制：`link_conclusion` 拒绝任何非 fact 级证据，且使用快照的 run
**缺少判断批次则拒绝生成报告**。复现契约覆盖"冻结快照之后"的全部环节，
不承诺"模型这次筛了什么"跨次一致。
AI 辅助开发的使用范围与人工审查流程见 `docs/ai_disclosure.md`（独立完成声明）。

### 5.1 当前改造进度（如实说明）

本作品正在从"演示原型"改造为**真实数据流水线**，决定记录见
`docs/redesign-decisions.md`：

- ✅ **第一批**：接入真实数据集 OBELiX（599 行 / 562 行可用 / 223 个真实 DOI）；
  冻结输入快照；三级信任模型（事实/判断/结论）；真实数据清洗（上界值留证、
  缺失归类、重复标注）；离线主线端到端。
- ✅ **第二批**：联网文献腿（Crossref / OpenAlex 元数据，不抓全文）；
  双腿 DOI 对接 + **异常驱动打断**（四条规则 + 人工确认闸门）；
  可插拔判断器（规则式基线 / 模型）与**反判据工具**；AGH 插件扩至
  10 个工具（新增检索 / 待判 / 提交裁决）。
- ✅ **真实模型实测**：在标准 OpenAI 兼容端点（DeepSeek）上跑通"模型生成检索式 +
  逐族裁决"，与规则式基线对比得出反判据判决 **`model_matters`**
  （模型 4 条检索式 vs 规则式 2 条；判定范围 7/42 vs 6/42，1 个族翻转）。
  结果存档 `evidence/model-judge-comparison.json`，幅度评估见设计文档 §9.5。
- ⬜ **待办**：AGH 会话内主路径端到端实跑（依赖交互式终端完成插件安装）。

**两处由实测带来的设计修正（重要）**：

1. **"两腿 DOI 高重合"假设被否证**：实测文献腿 373 篇 ∩ 数据腿 222 篇 = **仅 8 篇**。
   文献腿给话题全景、数据腿是特定数据集的来源论文，天然只少量重叠。
   故异常规则修正为：**低对接率不是异常**（只作指标），只有"交集为零"才判定异常。
2. **AGH 不能从 Python 当"补全 API"用**：`agh -p` 非交互下挂起（实测 150s 无输出）；
   `agh serve model-api` 是给人用的 Web 控制台。故模型判断的主路径改为
   **AGH 会话内判断**（LLM 调插件工具落盘裁决，Python 不调模型）。

**关键诚实声明**：仓库内快照由**规则式**判断产出（`judged_by=rule`，规则写在
`core/paper_agent/judge.py` 源码中）。模型判断路径已在标准 OpenAI 兼容端点
（DeepSeek）上实测跑通并出具反判据结论，且有 205 项离线测试覆盖接口、严格校验
与留痕机制。**但仍需注意：AGH 会话内主路径（LLM 调插件工具落盘裁决）尚未端到端
实跑**，该路径依赖交互式终端完成插件安装（AGH 安全设计要求人工确认，无 bypass）。
本次不把"会话内链路已跑通"写成已完成。

## 6. 验证方法

- **主线（真实数据，推荐）**：`bash demo/demo_mainline.sh` → 14 项断言全 PASS，
  末行 `DEMO_MAINLINE_OK`；覆盖快照强校验、599→562 全链路、两次运行逐字节一致、
  删除判断记录必须失败、判断留痕与证据回查；
- **确定性**：同一快照两次独立运行 `results.csv` SHA-256 全等（562 行排序结果）；
- **判断闸门（判据 4）**：删除快照 `judgments.jsonl` → run FAILED、报告无法生成；
  恢复后校验重新通过（`demo_mainline.sh` 第 [4] 项实测）；
- **legacy 回归**：`export PAPER_AGENT_SNAPSHOT=none` 后
  `demo_e2e.sh` → `DEMO_E2E_OK`；`demo_failure.sh` → 8 passed, 0 failed；
- **单测**：`python -m unittest discover -s tests` → **88/88 全绿**；
- **数据源核验**：`tools/probe_obelix.py`（只读、可离线复跑），
  实测 599 行 / 562 可用 / 37 上界值 / DOI 覆盖 100%，抽样 10 个 DOI 在
  Crossref 与 OpenAlex 均 10/10 可解析；
- **端到端证据**：`evidence/session-full.jsonl`（AGH 会话 42 条工具交互）与
  `audit-pack/`（含 events/provenance 双账本、verification.json、report.md、
  输入快照）。

三批测试样例：**正常**（真实数据全链路 DONE + P4 PASS）、
**边界**（p1_fail_all 降级 / 上界值 37 行排除留证 / P5 终态幂等复用）、
**失败**（mutate_summary → P4 FAIL → run FAILED；kill_after_p2 → 真实崩溃 + resume 恢复；
删除判断记录 → 报告闸门拒绝）。

## 7. 作品可运行性

```bash
# 任意机器（Python 3.10+ / Git Bash；零第三方依赖、主线无需网络与 key）
export PYTHONPATH=$PWD/core
python -m unittest discover -s tests -p "test_*.py"   # 88/88
bash demo/demo_mainline.sh                             # DEMO_MAINLINE_OK（14/0）
PAPER_AGENT_SNAPSHOT=none bash demo/demo_e2e.sh        # DEMO_E2E_OK
PAPER_AGENT_SNAPSHOT=none bash demo/demo_failure.sh     # 8 passed, 0 failed
```

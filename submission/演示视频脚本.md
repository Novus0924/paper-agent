- 画面：项目名 `paper-agent` + 一句话定位——"跑在 Agnes Harness 上、结论可追溯的科研 Agent"。
- 旁白：科研 Agent 的信任缺口：不可复现、不可审计、异常即黑箱。我们三个都用工程手段闭环。

## 1. 问题与架构（0:15–0:45）

- 画面：README 架构图（或白板动画）：AGH → 7 个 `sciret_*` JS 薄壳工具 → Python 核心（状态机 / 双账本 / 确定性实验）。
- 旁白强调两点：① Python 核心**零第三方依赖**；② LLM 只做编排，**不产出任何科学数字**。


- 画面：四段输出滚过，停在 `OK` / `DEMO_E2E_OK` / `DEMO_FAILURE_OK` / `TRUST_DEMO_OK`。
- 旁白：242 项单测、端到端、8 断言故障用例、账本篡改与伪造验证双拦截全部本地可
  复验——这是后面一切演示的底座。

## 3. AGH 真实会话：正常科研链路（1:30–2:45）

- 画面：已导出的真实会话账本（`evidence/session-6139563e.jsonl`），用编辑器滚动展示
  `tool/call → tool/result` 严格交替（**71 对，7 个 `sciret_*` 工具全部出现**）；
  点开 `runs/run-20261004-094544-e4d553/`（research 工作流，**6/6 步全 DONE**）：
  - `state.json`：`run_status: DONE`、六步全 `DONE`、`degraded: true`
    （真实降级：`semantic_scholar` 不可用已自动切源，任务未中断）；
  - `events.jsonl`：18 条事件，含 `degrade` 与 `run_finished`，R6 评审
    `verdict: Reject/Accept? → 需大修（Major Revision）`、`overall: 7.54`；
  - `provenance.jsonl`：**21 条证据**，`conclusions.jsonl`：**5 条结论**，每条带 `[EV-XXXX]` 回指；
  - `report.md` / `report.zh.md`：结论段每句都能追到 EV 编号；
  - `sciret_cite EV-0001` 回查真实 DOI 文献。
  - 旁白补充：`evidence/verify_export.py` 可当场跑，证明这份账本不是伪造的
    （逐行解析 + 核对 71 对配对 + 工具覆盖率）。
- 旁白：这不是模拟——是 AGH daemon 里 agnes-3.0-flash 逐次调用 7 工具的真实执行记录，
  0 命中也留证，证据先行是硬约束。

## 4. 高潮：真实崩溃 + 断点续跑（2:45–4:00）

- 画面：`evidence/session-full.jsonl` 第二轮（或现场重放 CLI）：
  1. `sciret_run_step P2_clean_data chaos=kill_after_p2` → 子进程被 `os._exit(137)` **真实杀死**；
  2. `sciret_status` → P1/P2 DONE、**P3 PENDING**，双账本逐行仍可解析（append-only 完整）；
  3. `sciret_resume` → DONE 步骤直接复用，只补跑 P3–P5 → `run_status DONE`；
  4. `sciret_verify` → 崩溃恢复后 SHA 与原始结果 `a30bc79f…` **完全一致**。
- 旁白：崩溃不是丢进度，而是留下可判断的断点；恢复后科学结论不受影响——这就是
  验证严谨与异常处理。

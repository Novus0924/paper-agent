# 演示视频脚本（3–5 分钟）

> 目标：一镜到底展示"真实 AGH 会话 + 可审计证据链 + 故障注入恢复"。
> 录制环境：Windows + Git Bash；终端字体调大；每段附预计时长与验收画面。

---

## 0. 标题页（0:00–0:15）

- 画面：项目名 `paper-agent` + 一句话定位——"跑在 Agnes Harness 上、结论可追溯的科研 Agent"。
- 旁白：科研 Agent 的信任缺口：不可复现、不可审计、异常即黑箱。我们三个都用工程手段闭环。

## 1. 问题与架构（0:15–0:45）

- 画面：README 架构图（或白板动画）：AGH → 7 个 `sciret_*` JS 薄壳工具 → Python 核心（状态机 / 双账本 / 确定性实验）。
- 旁白强调两点：① Python 核心**零第三方依赖**；② LLM 只做编排，**不产出任何科学数字**。

## 2. 秒级全绿验证（0:45–1:30）

```bash
cd paper-agent
python -m unittest discover -s tests -p "test_*.py"   # → Ran 39 tests OK
bash demo/demo_e2e.sh                                  # → DEMO_E2E_OK RUN=run-...
bash demo/demo_failure.sh                              # → 8 passed, 0 failed
```

- 画面：三段输出滚过，停在 `OK` / `DEMO_E2E_OK` / `DEMO_FAILURE_OK`。
- 旁白：39 项单测、端到端、8 断言故障用例全部本地可复验——这是后面一切演示的底座。

## 3. AGH 真实会话：正常科研链路（1:30–2:45）

- 画面：已导出的真实会话账本（`evidence/session.jsonl`），用 `jq` 或编辑器滚动展示
  `tool/call → tool/result` 交替；点开 `run-20261002-030119-61a0ec/`：
  - `state.json`：五步全 DONE、degraded=false；
  - `verification/verification.json`：5 项校验 PASS，results.csv SHA `a30bc79f…`；
  - `report.md`：结论 C1–C5 每条带 `[EV-XXXX]`；
  - `sciret_cite EV-0001` 回查真实 DOI 文献。
- 旁白：这不是模拟——是 AGH daemon 里 agnes-3.0-flash 逐次调用 7 工具的真实执行记录，
  0 命中也留证，证据先行是硬约束。

## 4. 高潮：真实崩溃 + 断点续跑（2:45–4:00）

- 画面：`evidence/session-full.jsonl` 第二轮（或现场重放 CLI）：
  1. `sciret_run_step P2_clean_data chaos=kill_after_p2` → 子进程被 `os._exit(137)` **真实杀死**；
  2. `sciret_status` → P1/P2 DONE、**P3 PENDING**，双账本逐行仍可解析（append-only 完整）；
  3. `sciret_resume` → DONE 步骤直接复用，只补跑 P3–P5 → `run_status DONE`；
  4. `sciret_verify` → 崩溃恢复后 SHA 与原始结果 `a30bc79f…` **完全一致**。
- 旁白：崩溃不是丢进度，而是留下可判断的断点；恢复后科学结论不受影响——这就是
  验证严谨与异常处理。

## 5. 审计包收尾（4:00–4:30）

```bash
bash audit-pack-template/build_audit_pack.sh run-20261002-033525-356ccf
ls audit-pack   # events/provenance/verification/report + 两份会话导出
```

- 旁白：一个 run 的全部可审计事实打成一个包，评审离线逐行核验；数据全部 as-reported、
  真实 DOI、严禁伪造。

## 6. 结尾（4:30–4:45)

- 画面：三行总结字幕：
  - **可复现**：确定性双跑 SHA-256 全等；
  - **可审计**：EV 证据链 + append-only 双账本；
  - **可恢复**：重试 / 降级 / 真实崩溃 / 断点续跑。

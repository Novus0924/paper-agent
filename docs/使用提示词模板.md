# paper-agent AGH 会话提示词模板

> 用途：接入 AGH 后，在会话里驱动 `sciret_*` 工具跑科研流水线的**可复用提示词**。
> 只改 `〈〉` 里的内容即可使用。插件安装见 [AGH插件安装指南.md](AGH插件安装指南.md)。

## 通用模板（复制后只改 〈〉 里的内容）

```
请使用科研流水线工具完成以下研究任务：

【研究主题】〈一句话写清领域和问题，如"图神经网络在药物发现中的应用"〉
【工作流】〈research=文献调研型 | materials=含实验执行（仅限内置电解质数据集领域）〉
【执行范围】〈research 填 R1_search 到 R6_review | materials 填 P1 到 P5〉

具体步骤：sciret_plan 以〈工作流〉规划"〈研究主题〉"任务并返回 run_id；
然后 sciret_run_step 依次执行〈执行范围〉；
sciret_status 查看最终状态；
sciret_report 生成报告；
最后 sciret_cite 回查一条关键文献证据。
```

## 选择参考

| 你想做什么 | 工作流 | 执行范围 |
|---|---|---|
| 调研任意领域文献、写综述 | `research` | `R1_search 到 R6_review` |
| 只看某主题有哪些文献 | `research` | `R1_search`（可加 `R2_read`） |
| 跑完整实验流水线（电解质） | `materials` | `P1 到 P5` |

**领域边界一句话**：检索与综述**不限领域**（真实联网四源：arXiv / Semantic Scholar / OpenAlex / CrossRef）；实验执行绑定内置数据集（固态电解质）领域，换领域需自带数据放入 `data/`。

## 精简变体

### 最短可用版（只填一个空）

```
用 sciret_plan 以 research 工作流规划"〈主题〉"并返回 run_id，然后 sciret_run_step 依次执行 R1_search 到 R6_review。
```

### 增强版（复现验证 + 证据回查，展示全链路卖点）

```
用 sciret_plan 以 research 工作流规划"〈主题〉"并返回 run_id；
sciret_run_step 依次执行 R1_search 到 R6_review；
sciret_verify 复现验证结果一致性；
sciret_report 生成报告并 sciret_cite 回查最重要的一条证据；
最后 sciret_status 汇总状态。
```

## 使用小贴士

1. **主题写具体一点**检索质量更好——"大语言模型幻觉缓解方法"比"AI"命中精准得多；
2. **同一主题重跑会复用检索快照**（事件标 `snapshot_reused`），想强制重新检索就微调主题措辞；
3. **跑完后资料位置**（`runs/<run_id>/` 下）：
   - `literature/` — 检索快照与命中列表（含四源状态、抓取时间、文献元数据）
   - `reading/pdfs/` — 精读环节真实下载的 PDF；`reading/notes/` — 精读笔记
   - `analysis/` `factcheck/` `writing/` `review/` — R3–R6 产物
   - `report.md` `state.json` `events.jsonl` `provenance.jsonl` — 报告与三本账
4. **中途失败/中断**，追加一句：

```
用 sciret_resume 恢复 run〈run_id〉继续执行剩余步骤。
```
